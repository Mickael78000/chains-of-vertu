# Blockchain Revolution Portfolio

A modern web application showcasing the intersection of blockchain technology, AI, and digital art.

## Tech Stack

- **Vite** - Fast build tool and dev server
- **React 18** - UI framework with lazy loading
- **TypeScript** - Type-safe development
- **Tailwind CSS** - Utility-first styling
- **Framer Motion** - Smooth animations with LazyMotion
- **shadcn/ui** - High-quality UI components
- **React Router** - Client-side routing
- **TanStack Query** - Data fetching and caching

## Features

- ⚡ Optimized bundle splitting and lazy loading
- 🎨 Smooth animations with reduced bundle size
- 📱 Fully responsive design
- 🔍 Global search functionality
- 🗜️ Brotli and Gzip compression
- 🎯 Tree-shaking optimizations
- 📊 Bundle analysis with visualizer

## Getting Started

### Prerequisites

- Node.js 18+ and npm

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Project Structure

```
src/
├── components/     # Reusable UI components
├── pages/          # Route pages
├── hooks/          # Custom React hooks
├── contexts/       # React contexts
└── lib/            # Utility functions
```

## Performance Optimizations

- Route-based code splitting
- Lazy-loaded components with React.lazy
- Optimized vendor chunking
- LazyMotion for reduced animation bundle
- Terser minification with console removal
- CSS minification
- Brotli and Gzip compression
